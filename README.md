# 펌프 잇 업 — 곡 선택 화면 순서 자료

오락실 **곡 선택 화면의 곡 순서**를 정리한 것입니다. 시리즈존 · 난이도존 ·
숏컷/리믹스/풀송 전용 채널 셋을 다룹니다.

> **이 저장소는 결과만 담습니다.** 순서를 알아내는 데 쓴 방송 영상·개인 플레이 기록은
> 들어 있지 않습니다. 근거의 **세기**는 각 표의 열(`확정도` · `상태`)과
> [검증 이력](docs/verification.md)이 말합니다.

## 무엇이 들어 있나

| 파일 | 크기 | 내용 |
|---|---:|---|
| `data/series_zone_order.csv` | 39 KB | 시리즈존(팩별 존) 안의 곡 순서. `확정도` 열이 판독 근거의 세기를 말한다 |
| `data/level_zone_order.csv` | 206 KB | 난이도존(S1~S26 · D5~D29) 채널의 곡 순서 **예측** |
| `data/channel_order.csv` | 12 KB | 숏컷·리믹스·풀송 전용 채널 순서. `상태` 열이 확정/예측을 가른다 |
| `level_zone_order.html` | 1362 KB | 난이도존을 채널별로 넘겨 보는 화면(단일 파일, 열면 바로 됨) |
| `series_zone_order.html` | 156 KB | 시리즈존 화면 |

## 어떻게 쓰나

CSV 는 그대로 읽으시면 되고, `.html` 은 **내려받지 않고 열어도** 되는 단일 파일입니다.
난이도존 화면은 채널을 좌우로 넘겨 보고, 번호를 눌러 **실제로 본 자리**를 적을 수 있습니다.

## 틀린 곳을 알려주시려면

이슈로 **채널 · 화면 번호 · 곡 이름** 세 가지만 주시면 충분합니다.
예) `S17 · 화면 042 · 실제로는 「비코즈 오브 유」`

## 규칙 요약

* **시리즈존** — 팩별로 묶이고, 그 안은 곡 번호 순
* **난이도존** — **카테고리 → 최신 시리즈 → 존 번호**. 아케이드 채보만 실립니다
* **전용 채널** — 숏컷·리믹스·풀송은 난이도존에 안 실리고 별도 채널에 모입니다.
  그 안의 순서는 **시리즈 역순 → 존 번호**이고 카테고리 축이 없습니다
* **화면 001 번은 곡이 아니라 RANDOM** 입니다. 곡은 002 번부터입니다

## 얼마나 믿을 수 있나 — **부분마다 다릅니다**

| 대상 | 곡 이름까지 확인한 비율 |
|---|---:|
| 시리즈존 | **100%** (638/638 전수 재판독) |
| 싱글존 | **5.3%** (128/2435 · 6채널만) |
| 더블존 | **0%** (규칙에서 나온 예측입니다) |
| 전용 채널 | **68%** (숏컷만 확정, 리믹스는 근거 0) |

숫자와 근거 시각은 [검증 이력](docs/verification.md) · [출처](docs/sources.md).
방법은 [method.md](docs/method.md).
